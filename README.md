# cursor_stuff

Личный репозиторий с заметками и конфигами для Cursor / Linux.

## Содержимое

| Папка | Описание |
|-------|----------|
| [8bitdo-ultimate2-steam/](8bitdo-ultimate2-steam/) | Ultimate 2: D-Input в Steam, udev, **сон/док/wake** на Bazzite |
| [8bitdo-xinput-poweroff-experimental/](8bitdo-xinput-poweroff-experimental/) | Эксперимент: попытка выключить геймпад в XInput (`310b`). Не проверено, не ставить по умолчанию |
