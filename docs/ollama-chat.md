# Опция: интерактивный чат playerbots через Ollama

Только вариант **playerbots**. NPCBots и lonewolf не отвечают языковой моделью.

Модуль [mod-ollama-chat](https://github.com/DustinHendrickson/mod-ollama-chat): боты отвечают на шепот, say и `/p` живым текстом. Команды вроде `follow` / `attack` в чёрном списке — их обрабатывает playerbots, не LLM.

Ollama ставится **на хост ВМ**, где проброшена видеокарта. Не в compose *arr и не отдельным GPU-контейнером (проще для 1660 Ti / 3070 Ti).

## Железо

| Карта | VRAM | Модель по умолчанию |
|---|---|---|
| GTX **1660 Ti** (сейчас) | 6 ГБ | `qwen2.5:3b` |
| RTX **3070 Ti** (через 3–4 недели) | 8 ГБ | `qwen2.5:7b` |

Qwen лучше держит **русский**, чем маленькая Llama. 7B на 1660 Ti часто не влезает целиком и уходит в RAM — ответы начинают тормозить. Пока 6 ГБ — не поднимайте 7B.

Проверка проброса: `nvidia-smi` на ВМ должен показать карту.

200 rndbot в мире **не** болтают все сразу: случайный чат выключен, бот-боту в say = 0, в очередь к GPU не больше одного запроса. Иначе 1660 Ti захлебнётся.

## Включение

Сервер playerbots уже установлен (native или Docker):

```bash
./scripts/enable-ollama-chat.sh playerbots
```

Скрипт: ставит Ollama, качает модель, клонирует модуль, пересобирает worldserver, глушит штатную болтовню playerbots. Первый прогон долгий (скачивание весов + cmake/docker build).

После замены карты на 3070 Ti:

```bash
OLLAMA_MODEL=qwen2.5:7b ./scripts/enable-ollama-chat.sh playerbots
```

В игре: `.ollama reload` подхватывает смену модели без рестарта, если world уже собран с модулем. Смена **самого модуля** (первый enable) требует пересборки — её делает скрипт.

## Как говорить

- Шепните боту по-русски (`/w Имя привет`) — самый предсказуемый канал.
- В группе обычная реплика в `/p`, не команда `follow`.
- Say рядом с ботом — может ответить один ближайший.
- Общий/торговля выключены, чтобы 200 ботов не забили канал и GPU.

ГМ: `.ollama reload`, `.ollama personality list`, `.ollama personality set Имя Gamer`.

## Порты

Ollama: **TCP 11434** только на ВМ. Друзьям **не** пробрасывать. Для Docker worldserver слушает `0.0.0.0:11434` на хосте, клиент контейнера — `host.docker.internal`.

## Выключить чат, не снимая модуль

В `mod_ollama_chat.conf`: `OllamaChat.Enable = 0`, затем `.ollama reload` или рестарт world. Ollama можно оставить для других задач.

## Не ставим

[mod-ollama-bot-buddy](https://github.com/DustinHendrickson/mod-ollama-bot-buddy) — LLM сама водит бота (квесты, путь). Это не чат, тяжелее для GPU и сырее. Нужен отдельный разговор, если захотите.
